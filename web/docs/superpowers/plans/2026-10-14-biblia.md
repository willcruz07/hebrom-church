# Bíblia no app — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Leitura da Bíblia completa (Almeida, domínio público) dentro da seção Palavra, com busca, navegação capítulo a capítulo e marcadores por usuário.

**Architecture:** Um script converte o USFX da Almeida em 66 JSONs estáticos (`public/bible/almeida/`) e num catálogo TS (`books.generated.ts`). Funções puras em `src/lib/bible/` (catálogo, parser de referência, busca) são testadas com `node --test`. O cliente lê os livros via Cache Storage (offline-first); os marcadores ficam em `bible_bookmarks/{uid}` no Firestore, num store zustand.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript strict, Tailwind v4, Firebase JS SDK v12, zustand, sonner, lucide-react, Node 24 (`node --test` com type stripping).

**Spec:** `web/docs/superpowers/specs/2026-10-14-biblia-design.md`

## Global Constraints

- Todos os caminhos abaixo são relativos a `web/`, e todos os comandos rodam de dentro de `web/`.
- Nenhuma dependência nova no `package.json`.
- Visual: âmbar (`amber-500/600/700`) como destaque; modais/sheets usam os componentes base (`Dialog`/`Sheet`), que já têm `backdrop-blur`.
- Datas do domínio são `Timestamp`; dentro de arrays usar `Timestamp.now()`, fora `serverTimestamp()`.
- Texto da UI em português.
- Não rodar o app (`npm run dev`) — verificar com testes, `npx tsc --noEmit` e `npm run lint`; o usuário testa no app.
- Não fazer commit sem o usuário pedir (os passos de "checkpoint" só verificam).
- Crédito exato: `Texto bíblico: João Ferreira de Almeida — domínio público.`
- Contagens esperadas: 66 livros, 1.189 capítulos, 31.098 versículos.
- Limite de marcadores: 200 por usuário.
- Módulos de `src/lib/bible/` testados por `node --test` usam imports relativos **com extensão `.ts`** e não acessam rede/DOM.

## Review Focus

1. Referência ambígua `jo` vs `jó` (João vs Jó) — `jo 3:16` deve abrir João; `jó 1:1` deve abrir Jó. → testes na Task 2.
2. Livros de um capítulo só: `judas 3` / `3jo 4` significam versículo, não capítulo. → testes na Task 2.
3. Busca com acento/maiúscula diferente (`ESPIRITO` acha "Espírito") e destaque na posição certa do texto original. → testes na Task 2.
4. Próximo/anterior nas bordas (fim de livro, Gênesis 1, Apocalipse 22). → testes na Task 2.
5. Sem internet com livro não baixado: tela mostra erro e "Tentar de novo" funciona (a promessa rejeitada não fica presa no cache em memória). → revisão de código na Task 3 (`getBook` remove a entrada do `Map` ao falhar).

```ts
export type Testament = 'VT' | 'NT'

/** Metadados de um livro (vêm do catálogo gerado, sem o texto). */
export interface BibleBookMeta {
  /** Código USFX, ex.: "JHN". Base do endereço dos marcadores. */
  id: string
  /** Usado na URL, ex.: "joao", "1-corintios". */
  slug: string
  name: string
  testament: Testament
  /** Abreviações em minúsculas, sem acento e sem espaço, ex.: ["jo", "joa"]. */
  abbrevs: string[]
  /** verses[i] = quantidade de versículos do capítulo i + 1. */
  verses: number[]
}

/** Texto de um livro: chapters[c][v] = capítulo c + 1, versículo v + 1. */
export interface BibleBookText {
  id: string
  slug: string
  name: string
  chapters: string[][]
}

export interface VerseRef {
  bookId: string
  chapter: number
  verse: number
}
```

```js
const source = process.argv[2]

const parsed = new Map()

    .slice(1)

      const number = Number(chunk.slice(0, chunk.indexOf('"')))
      if (number !== ci + 1) fail(`${id}: capítulo ${number} fora de ordem`)
      return [...chunk.matchAll(/<v id="(\d+)"\/>([\s\S]*?)<ve\/>/g)].map((m, vi) => {

const verseTotal = [...parsed.values()].flat().reduce((s, v) => s + v.length, 0)
if (chapterTotal !== EXPECTED.chapters) fail(`Esperava ${EXPECTED.chapters} capítulos, veio ${chapterTotal}`)
if (verseTotal !== EXPECTED.verses) fail(`Esperava ${EXPECTED.verses} versículos, veio ${verseTotal}`)

  const book = { id, slug, name, chapters: parsed.get(id) }
  writeFileSync(join(OUT_JSON, `${slug}.json`), JSON.stringify(book))
}

const meta = BOOKS.map(([id, slug, name, a], i) => ({
  id,
  slug,
  name,
  testament: i < 39 ? 'VT' : 'NT',
  abbrevs: a,
  verses: parsed.get(id).map((c) => c.length),
```

```ts
/** Minúsculas e sem acento — base da busca e do parser de referência. */
export function normalize(s: string): string {
  return s.normalize('NFD').replace(/[̀-ͯ]/g, '').toLowerCase()
}

/** Posição [início, fim) do termo no texto original, ignorando acento/maiúscula. */
export function findMatch(text: string, query: string): [number, number] | null {
  const q = normalize(query.trim())
  if (!q) return null

  let normalized = ''
  const origin: number[] = []
  for (let i = 0; i < text.length; i++) {
    const n = normalize(text[i])
    for (let k = 0; k < n.length; k++) origin.push(i)
    normalized += n
  }

  const at = normalized.indexOf(q)
  if (at < 0) return null
  return [origin[at], origin[at + q.length - 1] + 1]
}
```

```ts
import { BIBLE_BOOKS } from './books.generated.ts'
import { bookHref, chapterHref } from './catalog.ts'
import { normalize } from './text.ts'
import type { BibleBookMeta } from './types.ts'

export interface ParsedReference {
  book: BibleBookMeta
  chapter?: number
  verse?: number
}

// [número do livro] nome [capítulo [:versículo] [-fim]]
const PATTERN = /^([1-3])?\s*(\p{L}+)\.?\s*(?:(\d+)(?:\s*[:.,]\s*(\d+))?(?:\s*-\s*\d+)?)?$/u

const compactName = (book: BibleBookMeta) => book.name.toLowerCase().replace(/\s+/g, '')

function findBook(raw: string): BibleBookMeta | null {
  const key = normalize(raw)
  return (
    // 1º nome exato com acento ("jó" → Jó), antes das abreviações ("jo" → João)
    BIBLE_BOOKS.find((b) => compactName(b) === raw) ??
    BIBLE_BOOKS.find((b) => b.abbrevs.includes(key)) ??
    BIBLE_BOOKS.find((b) => normalize(compactName(b)) === key) ??
    uniquePrefix(key)
  )
}

function uniquePrefix(key: string): BibleBookMeta | null {
  if (key.replace(/^\d/, '').length < 3) return null
  const found = BIBLE_BOOKS.filter((b) => normalize(compactName(b)).startsWith(key))
  return found.length === 1 ? found[0] : null
}

/** "jo 3:16", "1co13", "Sl 23", "joão" → livro/capítulo/versículo; null se não for referência válida. */
export function parseReference(input: string): ParsedReference | null {
  const match = input.trim().toLowerCase().replace(/\s+/g, ' ').match(PATTERN)
  if (!match) return null

  const [, number = '', word, ch, vs] = match
  const book = findBook(number + word)
  if (!book) return null
  if (!ch) return { book }

  let chapter = Number(ch)
  let verse = vs ? Number(vs) : undefined
  // Livro de um capítulo só: "Judas 3" é o versículo 3
  if (verse === undefined && book.verses.length === 1 && chapter > 1) {
    verse = chapter
    chapter = 1
  }

  if (chapter < 1 || chapter > book.verses.length) return null
  if (verse === undefined) return { book, chapter }
  if (verse < 1 || verse > book.verses[chapter - 1]) return null
  return { book, chapter, verse }
}

export function referenceHref(ref: ParsedReference): string {
  return ref.chapter ? chapterHref(ref.book.slug, ref.chapter, ref.verse) : bookHref(ref.book.slug)
}
```

```ts
import { normalize } from './text.ts'
import type { BibleBookText } from './types.ts'

export const MIN_SEARCH_LENGTH = 3
export const MAX_SEARCH_RESULTS = 50

export interface SearchHit {
  bookId: string
  chapter: number
  verse: number
  text: string
}

// Normalizar 31 mil versículos a cada tecla seria desperdício: guarda por livro
const normalizedCache = new WeakMap<BibleBookText, string[][]>()

function normalizedChapters(book: BibleBookText): string[][] {
  let chapters = normalizedCache.get(book)
  if (!chapters) {
    chapters = book.chapters.map((verses) => verses.map(normalize))
    normalizedCache.set(book, chapters)
  }
  return chapters
}

/** Versículos que contêm o termo (sem acento/maiúscula), na ordem dos livros recebidos. */
export function searchVerses(books: BibleBookText[], query: string, limit = MAX_SEARCH_RESULTS): SearchHit[] {
  const q = normalize(query.trim())
  if (q.length < MIN_SEARCH_LENGTH) return []

  const hits: SearchHit[] = []
  for (const book of books) {
    const chapters = normalizedChapters(book)
    for (let c = 0; c < chapters.length; c++) {
      for (let v = 0; v < chapters[c].length; v++) {
        if (!chapters[c][v].includes(q)) continue
        hits.push({ bookId: book.id, chapter: c + 1, verse: v + 1, text: book.chapters[c][v] })
        if (hits.length >= limit) return hits
      }
    }
  }
  return hits
}
```

```ts
import { BIBLE_BOOKS } from './books.generated'
import type { BibleBookText } from './types'

// Trocar o texto no futuro = novo nome de cache; os antigos são apagados no prefetch
const CACHE_NAME = 'bible-almeida-v1'
const CACHE_PREFIX = 'bible-almeida-'
const PARALLEL_DOWNLOADS = 6

const bookUrl = (slug: string) => `/bible/almeida/${slug}.json`
const loaded = new Map<string, Promise<BibleBookText>>()

async function openCache(): Promise<Cache | null> {
  try {
    return typeof caches === 'undefined' ? null : await caches.open(CACHE_NAME)
  } catch {
    // Janela privada / armazenamento bloqueado: segue só com a rede
    return null
  }
}

async function fetchBook(slug: string): Promise<BibleBookText> {
  const url = bookUrl(slug)
  const cache = await openCache()
  const cached = await cache?.match(url)
  if (cached) return cached.json()

  const response = await fetch(url)
  if (!response.ok) throw new Error(`Falha ao baixar ${slug}: ${response.status}`)
  await cache?.put(url, response.clone()).catch(() => {})
  return response.json()
}

/** Texto do livro: memória → Cache Storage → rede. */
export function getBook(slug: string): Promise<BibleBookText> {
  let promise = loaded.get(slug)
  if (!promise) {
    promise = fetchBook(slug)
    loaded.set(slug, promise)
    // Falhou (ex.: offline): sai da memória para o "Tentar de novo" buscar outra vez
    promise.catch(() => loaded.delete(slug))
  }
  return promise
}

/** Todos os livros, na ordem canônica. Baixa o que faltar, em lotes. */
export async function getAllBooks(onProgress?: (done: number, total: number) => void): Promise<BibleBookText[]> {
  const books: BibleBookText[] = []
  for (let i = 0; i < BIBLE_BOOKS.length; i += PARALLEL_DOWNLOADS) {
    const batch = BIBLE_BOOKS.slice(i, i + PARALLEL_DOWNLOADS)
    books.push(...(await Promise.all(batch.map((b) => getBook(b.slug)))))
    onProgress?.(books.length, BIBLE_BOOKS.length)
  }
  return books
}

async function deleteOldCaches() {
  try {
    const keys = await caches.keys()
    await Promise.all(keys.filter((k) => k.startsWith(CACHE_PREFIX) && k !== CACHE_NAME).map((k) => caches.delete(k)))
  } catch {
    // sem Cache Storage: nada a limpar
  }
}

let prefetchStarted = false

/** Baixa a Bíblia inteira para o aparelho quando o navegador estiver ocioso (uma vez por sessão). */
export function prefetchBible(): void {
  if (prefetchStarted || typeof window === 'undefined') return
  prefetchStarted = true

  const run = () => {
    void deleteOldCaches()
    getAllBooks().catch(() => {
      // Sem internet: tenta de novo na próxima visita
      prefetchStarted = false
    })
  }
  if ('requestIdleCallback' in window) window.requestIdleCallback(run)
  else setTimeout(run, 2000)
}
```

```ts
import { db } from './config'
import type { BibleBookmark } from '@/types'

// Um documento por usuário (fora de `users`, para não pesar nas listas de membros):

const BIBLE_BOOKMARKS_COLLECTION = 'bible_bookmarks'
export const MAX_BIBLE_BOOKMARKS = 200

const bookmarksDoc = (uid: string) => doc(db, BIBLE_BOOKMARKS_COLLECTION, uid)

const readItems = (data: DocumentData | undefined): BibleBookmark[] =>
  Array.isArray(data?.items) ? (data.items as BibleBookmark[]) : []

export async function getBookmarks(uid: string): Promise<BibleBookmark[]> {
  return readItems((await getDoc(bookmarksDoc(uid))).data())
}

function updateBookmarks(uid: string, change: (items: BibleBookmark[]) => BibleBookmark[]) {
  return runTransaction(db, async (tx) => {
    const snapshot = await tx.get(bookmarksDoc(uid))
    const items = change(readItems(snapshot.data()))
    tx.set(bookmarksDoc(uid), { items, updated_at: serverTimestamp() })
    return items
  })
}

/** Adiciona o marcador (sem duplicar); passando de 200, o mais antigo sai. */
export const addBookmark = (uid: string, ref: string) =>
  updateBookmarks(uid, (items) =>
    items.some((i) => i.ref === ref)
      ? items
      : [...items, { ref, created_at: Timestamp.now() }]
          .sort((a, b) => a.created_at.toMillis() - b.created_at.toMillis())
          .slice(-MAX_BIBLE_BOOKMARKS),
  )

export const removeBookmark = (uid: string, ref: string) =>
  updateBookmarks(uid, (items) => items.filter((i) => i.ref !== ref))
```

```ts
interface BibleBookmarksState {

  items: BibleBookmark[]
  status: 'idle' | 'loading' | 'ready' | 'error'

  uid: null,
  items: [],
  status: 'idle',

    if (current === uid && (status === 'loading' || status === 'ready')) return

    set({ uid, items: [], status: 'loading' })
    try {
      const items = await getBookmarks(uid)
      if (get().uid === uid) set({ items, status: 'ready' })
    } catch (error) {
      console.error(error)
      if (get().uid === uid) set({ status: 'error' })

  },

    const exists = previous.some((i) => i.ref === ref)
```

```tsx
import { ArrowRight, Search, X } from 'lucide-react'

import { parseReference, referenceHref } from '@/lib/bible/reference'
import { MAX_SEARCH_RESULTS, MIN_SEARCH_LENGTH, searchVerses, type SearchHit } from '@/lib/bible/search'
import { findMatch, normalize } from '@/lib/bible/text'

function Highlighted({ text, query }: { text: string; query: string }) {
  const match = findMatch(text, query)
  if (!match) return <>{text}</>
  const [start, end] = match
  return (
    <>
      {text.slice(0, start)}
      <mark className="rounded bg-amber-100 px-0.5 text-amber-900 dark:bg-amber-900/40 dark:text-amber-200">
        {text.slice(start, end)}
      </mark>
      {text.slice(end)}
    </>
  )
}

/** Uma caixa só: "jo 3:16" leva ao versículo; uma palavra lista os versículos que a contêm. */
export function BibleSearch() {
  const router = useRouter()
  const [query, setQuery] = useState('')
  const [hits, setHits] = useState<SearchHit[]>([])
  const [searchedFor, setSearchedFor] = useState('')
  const [progress, setProgress] = useState<number | null>(null)

  const reference = useMemo(() => parseReference(query), [query])
  const term = query.trim()
  const isWordSearch = normalize(term).length >= MIN_SEARCH_LENGTH

  useEffect(() => {
    if (!isWordSearch) {
      setHits([])
      setSearchedFor('')
      return
    }

    let cancelled = false
    const timer = setTimeout(async () => {
      try {
        const books = await getAllBooks((done, total) => {
          if (!cancelled) setProgress(done < total ? done : null)
        })
        if (cancelled) return
        setHits(searchVerses(books, term))
        setSearchedFor(term)
      } catch {
        if (!cancelled) toast.error('Sem conexão para baixar a Bíblia. Tente novamente.')
      } finally {
        if (!cancelled) setProgress(null)
      }
    }, 300)

    return () => {
      cancelled = true
      clearTimeout(timer)
    }
  }, [term, isWordSearch])

  const firstHref = reference ? referenceHref(reference) : hits[0] ? verseHref(hits[0]) : null
  const showEmpty = isWordSearch && searchedFor === term && hits.length === 0 && !reference

  return (
    <div className="space-y-3">
      <form
        role="search"
        onSubmit={(e) => {
          e.preventDefault()
          if (firstHref) router.push(firstHref)
        }}
        className="relative"
      >
        <Search className="pointer-events-none absolute left-4 top-1/2 h-5 w-5 -translate-y-1/2 text-slate-400" />
        <Input
          value={query}
          onChange={(e) => setQuery(e.target.value)}
          placeholder='Buscar: "jo 3:16" ou uma palavra'
          aria-label="Buscar na Bíblia"
          className="h-12 rounded-2xl pl-12 pr-10 text-base"
        />
        {query && (
          <button
            type="button"
            onClick={() => setQuery('')}
            aria-label="Limpar busca"
            className="absolute right-3 top-1/2 -translate-y-1/2 rounded-full p-1 text-slate-400 hover:text-slate-700"
          >
            <X className="h-4 w-4" />
          </button>
        )}
      </form>

      {(reference || progress !== null || hits.length > 0 || showEmpty) && (

            </Link>
          )}

          {progress !== null && (
            <div className="flex items-center gap-3 px-4 py-3 text-sm text-slate-500">
              <HebromSpinner size="sm" />
              Preparando a Bíblia… {progress}/66
            </div>
          )}

          {hits.length > 0 && (
            <ul className="max-h-[60vh] divide-y divide-slate-100 overflow-y-auto dark:divide-slate-800">
```

```tsx
                  (flash === verse || selected === verse) && 'bg-amber-100 dark:bg-amber-900/30',
                )}
              >
                <sup className="mr-1 font-sans text-[0.65em] font-bold text-amber-600 dark:text-amber-400">
                  {verse}
                </sup>
                {text}
                {bookmarked.has(refKey(verse)) && (
                  <Bookmark
                    className="ml-1 inline h-[0.8em] w-[0.8em] fill-amber-500 align-baseline text-amber-500"
                    aria-label="Marcado"
                  />
                )}
              </button>
            )
          })}
        </div>
      )}

      {verses && (
        <nav className="space-y-3 border-t border-slate-200 pt-6 dark:border-slate-800">
          {next && (
            <Button
              asChild
              size="lg"
              className="h-auto w-full rounded-2xl bg-amber-600 py-4 text-base shadow-lg shadow-amber-500/20 hover:bg-amber-700"
            >
              <Link href={chapterHref(next.slug, next.chapter)}>
                Próximo: {next.name} {next.chapter}
                <ChevronRight className="ml-1 h-5 w-5" />
              </Link>
            </Button>
          )}
          {prev && (
            <Link
              href={chapterHref(prev.slug, prev.chapter)}
              className="flex items-center justify-center gap-1 text-sm text-slate-500 hover:text-amber-700 dark:hover:text-amber-400"
            >
              <ChevronLeft className="h-4 w-4" />
              {prev.name} {prev.chapter}
            </Link>
          )}
        </nav>
      )}

      <BibleCredit />

      <Sheet open={selected !== null} onOpenChange={(open) => !open && setSelected(null)}>
        <SheetContent side="bottom" className="rounded-t-3xl">
          <SheetHeader>
            <SheetTitle>{selectedLabel}</SheetTitle>
            <SheetDescription className="line-clamp-3 font-serif italic">{selectedText}</SheetDescription>
          </SheetHeader>
          <div className="grid gap-2 px-4 pb-6 sm:grid-cols-3">
            <Button
              className="bg-amber-600 hover:bg-amber-700"
              disabled={!currentUser}
              onClick={() => {
                if (currentUser && selected) toggle(currentUser.uid, refKey(selected))
                setSelected(null)
              }}
            >
              <Bookmark className={cn('mr-2 h-4 w-4', selectedMarked && 'fill-white')} />
              {selectedMarked ? 'Remover marcador' : 'Adicionar marcador'}
            </Button>
            <Button
              variant="outline"
              onClick={() => {
                copyText(quote)
                setSelected(null)
              }}
            >
              <Copy className="mr-2 h-4 w-4" />
              Copiar
            </Button>
            <Button
              variant="outline"
              onClick={() => {
                shareText(quote)
                setSelected(null)
              }}
            >
              <Share2 className="mr-2 h-4 w-4" />
              Compartilhar
            </Button>
          </div>
        </SheetContent>
      </Sheet>
    </article>
  )
}
```
